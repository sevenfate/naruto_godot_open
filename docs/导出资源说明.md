# 导出客户端时的非导入资源

Godot 导出包中的 `res://` 是资源虚拟文件系统。地图素材目录的存在性检查应直接使用
`DirAccess.dir_exists_absolute("res://...")`；先调用 `ProjectSettings.globalize_path()`
会转成项目或可执行文件旁的物理路径，无法判断只存在于 PCK 中的目录。

## JSON 和天气原始 PNG

导出时还需要在“非资源文件/文件夹的导出过滤器”中显式保留代码通过 `FileAccess`
读取的文件。地图和其他配置需要 `*.json`。

`脚本/地图/天气特效.gd` 的 `烘帧任务.读图()` 使用 `FileAccess` 读取原图，再调用
`Image.load_png_from_buffer()` 解码、裁切。只有 Godot 导入后的纹理不够，还需要这些目录的
原始 PNG。在已补齐完整素材的本地工程中，可将以下过滤器用逗号连接：

```text
*.json
素材/地图/雷之国/地图物件/Obj_acc_shuizhiguo_nature_16/*.png
素材/地图/112040002/地图物件/Obj_acc_shuizhiguo_nature_17/*.png
素材/地图/雨隐村/地图物件/Obj_acc_shuizhiguo_nature_18/*.png
```

这些是导出配置说明，不是把素材加入源码仓库。素材仍按 `素材/README.md` 在本地补齐，
不得随 PR 提交。本文不添加特定平台的导出预设，也不改变脚本编译模式。

## 不依赖素材的目录回归

```bash
python 测试/跑地图资源包回归.py --godot /path/to/godot
```

也可以通过环境变量 `NARUTO_GODOT` 指定 Godot 4.7.x，再运行该 Python 脚本。
脚本在临时最小工程内复制实际的 `地图资源.gd` 和测试，避免加载游戏主题和自动加载节点。
测试动态生成并挂载只有占位文本的 PCK；同名物理目录不存在，所以不会因本地已有素材而误通过。

覆盖索引命中、本地图回退、失效索引回退、目录不存在和包内文件读取。
旧代码应有 3 项失败；修复后应为 `地图资源包回归：通过（7 项检查，红 0 项）`。
该测试不验证 PNG 解码或完整天气渲染。
